# AgentMotionBench

Can coding agents recreate and edit whole-body motion?

Source of the project page: https://agentmotionbench.github.io/

This folder is generated: the page, its data and its media are built from the benchmark's run records by
`bench/build_site.py --public --bundle <this folder>` in the benchmark repository. Do not edit files here by hand.
